# نور

تطبيق عربي فاخر لمرافقة القرآن الكريم، يعمل كتطبيق ويب (PWA) وكتطبيق أندرويد (APK) عبر Capacitor.

## المميزات
- المصحف كاملاً بخط أميري قرآن، مع العلامات المرجعية وآخر موضع قراءة.
- بحث في الآيات، وتفسير ميسّر لكل آية.
- التسميع بالصوت مع تصحيح الكلمات.
- المراجعة بالتكرار المتباعد لما حفظته.
- مواقيت الصلاة مع تنبيهات، واتجاه القبلة.
- الأذكار والتسبيح.
- مساعد ذكي للأسئلة (مجاني، أو بمفتاحك الخاص).
- أهداف يومية، سلسلة أيام، إحصاءات، وأوسمة إنجاز.
- ثيم داكن وفاتح، وتلاوات بأصوات عدة قرّاء.

## التثبيت على أندرويد
1. افتح صفحة Releases في هذا المستودع وحمّل أحدث ملف `Noor-Quran-*.apk`.
2. افتح الملف واسمح بالتثبيت من مصادر غير معروفة إذا طلب الجهاز ذلك.
3. ثبّت التطبيق ثم افتحه.

## الاستخدام على الآيفون
افتح النسخة الويب في Safari، اضغط زر المشاركة، ثم "إضافة إلى الشاشة الرئيسية". سيعمل كتطبيق مستقل.

## للمطورين
```bash
npm install        # تثبيت الحزم
npm run dev        # تشغيل محلي
npm run build      # بناء dist/
npm test           # الاختبارات
```
بناء APK يتم تلقائياً عبر GitHub Actions (`.github/workflows/android.yml`) عند كل push إلى main، وينشر إصداراً جديداً في Releases.

## الذكاء الاصطناعي (v1.1)
- **خادم نور** (`supabase/functions/noor-ai`): يربط التطبيق تلقائياً بـ Gemini ثم Groq ثم OpenRouter ثم Pollinations، وينتقل للتالي عند نفاد الحصة. المفاتيح محفوظة في أسرار Supabase فقط وليست داخل التطبيق.
- **التسميع الدقيق**: تسجيل الصوت وتفريغه بنموذج Whisper large-v3، ومطابقة كلمة بكلمة مع تجاهل الاستعاذة والبسملة.
- **تقييم التجويد**: يستمع Gemini للتسجيل ويعطي درجة وملاحظات على الأحكام والأخطاء.
- **مركز التدريب**: الآية التالية، التلقين، أخطائي، تحدي اليوم، أوائل الكلمات.
