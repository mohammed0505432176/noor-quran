# توقيع نسخة أندرويد (APK)

**لا يُخزَّن أي مفتاح توقيع في المستودع.** نسخة الإصدار تُوقَّع بمفتاح يُقرأ من أسرار GitHub فقط
(`.github/workflows/android.yml`). إن غابت الأسرار يتوقف البناء برسالة واضحة ولا يُنتج APK غير موقّع أو موقّع بمفتاح عام.

## لماذا تغيّر المفتاح

كان المفتاح القديم (`release.keystore.b64`) منشوراً في المستودع وكلمة مروره ثابتة في سير العمل، لذلك يُعدّ **مكشوفاً**:
أي شخص يستطيع توقيع APK بالمفتاح نفسه، وأجهزة من ثبّتت النسخة القديمة قد تقبله كتحديث لنور. لا يمكن إصلاح ذلك بالإبقاء على المفتاح نفسه.

## أثر التدوير على المستخدمين الحاليين

- أندرويد يرفض تثبيت APK موقّع بمفتاح مختلف فوق تطبيق مثبّت. **المستخدم الحالي يحتاج مرة واحدة إلى حذف نور ثم تثبيت النسخة الجديدة.**
- الحذف يمسح البيانات المحلية على الجهاز (التقدّم، الإعدادات، التسجيلات) ما لم يُصدَّر منها نسخة احتياطية قبل الحذف.
- بعد التثبيت الجديد تستمر التحديثات العادية بالمفتاح الجديد دون حذف.
- النسخة القديمة التي وُقّعت بالمفتاح المكشوف لا تُحدَّث تلقائياً بالمفتاح الجديد؛ يجب إعلان ذلك في ملاحظات الإصدار.

**خيار مؤجَّل يحتاج قراراً:** دعم تدوير المفاتيح (`apksigner rotate`) يتيح تحديثاً بلا حذف، لكنه لا يحمي من يملك المفتاح القديم المكشوف
لأن هذا المفتاح معروف للجميع. لذلك لم يُعتمد.

## إعداد المفتاح الجديد (مرة واحدة، على جهازك)

```bash
keytool -genkeypair -v -keystore noor-release.jks -alias noor -keyalg RSA -keysize 2048 -validity 10000
```

احفظ الملف `noor-release.jks` وكلمتي المرور في مكان آمن خارج المستودع (مدير كلمات مرور). ثم أضف أسرار المستودع:

| اسم السر | القيمة |
|---|---|
| `NOOR_KEYSTORE_B64` | محتوى `noor-release.jks` مشفّراً Base64 (سطر واحد) |
| `NOOR_STORE_PASSWORD` | كلمة مرور المخزن |
| `NOOR_KEY_PASSWORD` | كلمة مرور المفتاح |
| `NOOR_KEY_ALIAS` | اختياري، الافتراضي `noor` |

```bash
base64 -w0 noor-release.jks | gh secret set NOOR_KEYSTORE_B64
gh secret set NOOR_STORE_PASSWORD
gh secret set NOOR_KEY_PASSWORD
```

على Windows (PowerShell) حوّل الملف بـ:
`[Convert]::ToBase64String([IO.File]::ReadAllBytes("noor-release.jks"))`

## بصمة الشهادة

بعد أول بناء ناجح تظهر بصمة SHA-256 للشهادة في صفحة الإصدار. انشرها مع الإصدار حتى يتحقق المستخدم من أصالة APK.

## ملاحظات

- التاريخ القديم للمستودع ما زال يحتوي على المفتاح المنشور؛ لا يُعاد كتابة التاريخ لأن المفتاح يُعتبر مكشوفاً على كل حال.
- لا تضع المفتاح أو كلمات المرور في الملفات أو سجلات البناء.
